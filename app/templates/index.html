읽기 격리 점검
확인 전

      
점검 결과는 ERROR, UNSAFE_FULL_DISK_READ, SAFE_CANDIDATE 중 하나입니다. 이 버전에서는 실제 실행을 계속 잠가 둡니다.

      
    


    

      
WSL2
bubblewrap 읽기 전용 사전 점검
미설정

      
WSL2 배포판을 직접 선택하세요. 고정 bwrap 카나리 점검은 사전 점검으로만 동작하며 실제 실행을 절대 열지 않습니다.

      

        
        
        
        
      

      
선택한 배포판, `/usr/bin/python3`, `bwrap`만 확인합니다. 샌드박스는 Capsule을 `/work`에 읽기 전용으로 연결하고 Windows 마운트는 연결하지 않으며 실행 버튼은 계속 잠급니다.

      
반복성 점검은 SAFE_CANDIDATE 이후에만 사용할 수 있으며 실제 실행은 계속 잠겨 있습니다.

      

        
봉인 런타임
WSL Codex 0단계
미설정

        
허용 목록에 있는 WSL 네이티브 바이너리 하나를 설정하세요. 이 단계는 메타데이터만 검증하며 외부 통신과 모든 Codex 시작은 차단됩니다.

        

          
          
          
        

        
설정 여부, 버전 일치, 런타임 지문, 격리 일치, 외부 통신 차단 여부만 표시합니다. 경로, argv, 환경값, 자격 증명은 표시하지 않습니다.

      

      

        
봉인 외부 통신
계약 1단계
미설정

        
변경할 수 없는 사용자 지정 공급자와 브로커 계약만 생성합니다. 이 단계에서는 릴레이, 소켓, 네트워크, 인증, Codex 프로세스를 시작하지 않습니다.

        

        
계약은 루프백 Responses 엔드포인트 하나와 향후 Unix 소켓 브로커 경계 하나만 허용합니다. 인증은 미설정 상태로 유지되며 모든 시작은 잠겨 있습니다.

3.1단계 증명 관문
가짜 실행 차단

        
가짜 결과는 별도 실행기 신원을 가지며 실제 WSL 증명으로 사용할 수 없습니다.

        

        
실제 실행기
1회용 WSL 실행 창
WSL 미실행

        
신선한 Canary, SAFE_REPRODUCIBLE 10/10/10, 변경 불가 Contract, 정확한 실행기 해시 검증을 모두 통과한 뒤에만 로컬 IPv4 루프백 클릭으로 2분짜리 창 하나를 만들 수 있습니다. 다음 요청이 두 nonce를 모두 소비하며 런타임과 실제 실행은 계속 잠겨 있습니다.

        

          
          
        

        

          
오프라인 Codex
봉인 프로세스 Canary
비활성

          
기본 경로는 계속 비활성입니다. 명시적인 로컬 IPv4 루프백 클릭 한 번으로 서버 내부에서 봉인 Permit, Canary 창, 1회용 청구를 수행하고 외부 모델 토큰 0인 가짜 응답만 확인합니다. 런타임과 실제 실행은 계속 잠겨 있습니다.
